# 다음 기회 — IT 활동 탐색

서울·경기·온라인에서 참가 가능한 해커톤, 부트캠프, 공모전을 단계별로 탐색하는 정적 웹페이지입니다.

**[웹페이지 바로 열기](https://raw.githack.com/minuk1749/it-opportunity-board/main/index.html)**

현재 접속 링크는 GitHub 소스를 표시하는 githack 미리보기입니다. 처음 열 때 출처 안내 화면이 나오면 이 저장소의 주소를 확인할 수 있습니다. GitHub Pages는 아래 설정을 활성화하면 사용할 수 있습니다.

## 기능

- 종류 선택 → 분야 선택 → 공고 목록 → 상세 정보
- 이름·기술·지역 검색, 마감일·이름순 정렬
- 온라인·오프라인·혼합 방식 필터, 조건 확인 공고 제외
- 브라우저 로컬 저장 목록
- 마감까지 남은 날짜를 한국시간으로 계산
- 모바일 화면, 키보드 탐색, 상세 대화상자

## 실행

Node.js 20 이상에서 `npm start`를 실행하고 http://127.0.0.1:4317 을 엽니다. 설치할 패키지는 없습니다.

`npm run check`로 JavaScript 문법과 공고 데이터의 기본 무결성을 검사합니다.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. 프레임워크 빌드나 서버가 필요 없습니다. `.nojekyll`로 파일을 그대로 게시합니다.

[이 저장소의 Pages 설정](https://github.com/minuk1749/it-opportunity-board/settings/pages)에서 설정할 수 있습니다.

## 공고 업데이트

`catalog.json`의 `verifiedAt`과 `items`를 수정한 뒤 main 브랜치에 커밋합니다. GitHub Pages가 변경 내용을 다시 배포합니다. `id`는 기존 북마크를 보존하기 위해 유지합니다.

초기 목록은 2026년 11월 3일 조사한 37개 공고입니다. ChatGPT의 기존 정기 조사 작업이 **11월 6일부터 3일마다 한국시간 오전 9시 전후**에 공식 공고를 조사하고 이 저장소의 `catalog.json`을 갱신하도록 연결되어 있습니다. 실행·검색·연결 실패 시에는 마지막 정상 자료를 유지하며, 작업 결과에서 실패 이유를 알립니다.

사이트는 GitHub의 최신 공고 데이터를 직접 읽고, 접속 중에도 5분마다 다시 확인합니다. 검색을 입력 중이거나 상세 창을 열었을 때는 자동 화면 갱신을 잠시 미룹니다. `최신 목록 불러오기` 버튼은 이미 게시된 자료를 다시 불러오며 새 웹 조사를 즉시 실행하는 버튼은 아닙니다.

상단에는 마지막 조사일·다음 예정 시각·최근 갱신 기록이 표시됩니다. 다음 예정 시각은 저장된 일정을 기준으로 한 예상이며 실행 완료를 의미하지 않습니다. 예정 시각이 24시간 넘게 지나도록 자료가 갱신되지 않으면 확인 필요 상태를 표시합니다. `verifiedAt`과 `lastResearchAt`은 실제 조사가 완료되었을 때만 갱신합니다.

일반 갱신 작업의 데이터 규격·검증·충돌 처리·읽기 검증 절차는 [UPDATE-INSTRUCTIONS.md](UPDATE-INSTRUCTIONS.md)를 따릅니다. 브라우저를 닫아도 정기 조사 작업은 예약에 따라 실행되며, 방문자의 컴퓨터에서 크롤러나 비밀 토큰을 실행하지 않습니다.

`uncertain: true`는 휴학생 자격, 국비카드, 필수 참석 장소 등 확인할 조건이 남은 공고입니다. `deadlineTime`은 안내 문구이며 시각이 공개되지 않은 공고는 마감일 종료까지 표시됩니다. 같은 날짜에서 시각이 명시된 공고는 그 시각을 기준으로 마감을 계산합니다.

공고의 내용과 참가 조건은 주최 기관의 원문이 우선합니다. 북마크는 현재 브라우저의 localStorage에만 저장됩니다.


## 산업기능요원 채용

[채용 화면 열기](https://raw.githack.com/minuk1749/it-opportunity-board/main/index.html#/careers)

2026-11-07에 기존 11/2 채용 조사 내용을 통합했습니다. 총 78개 회사 기록(신규 지정 후보 42곳 포함), 변경 기록 38건, 조사일 4개를 보존했습니다. 이 숫자는 최초 통합 기준이며 모두 현재 채용 중이라는 의미는 아닙니다. 회사별 실제 원문 확인일, 플랫폼별 마감과 편입 조건을 확인하세요.

- 회사 검색, 상태·근무지·기술 필터, 검토 순서·최근 확인일·이름순 정렬
- 날짜별 변경 전/후·다음 행동·근거, 회사별 전체 이력
- 브라우저에 회사 저장, 기존 활동 북마크와 별도 유지
- 채용은 기존 매주 월요일 오전 9시 전후 조사, 활동은 3일 간격 유지
- careers.json은 기존 조사일을 보존하며 페이지 새로고침으로 확인일을 바꾸지 않음

채용 갱신 계약은 [CAREER-UPDATES.md](CAREER-UPDATES.md)입니다. 행사 조사는 계속 catalog.json을 사용하고, 채용 조사는 careers.json만 수정합니다. 두 자동화는 서로의 데이터를 덮어쓰지 않습니다. npm run check로 두 데이터 파일과 일정·실패 시 보존·필터·이력 참조를 검사합니다. node bundle.mjs로 두 화면을 포함한 정적 미리보기를 생성할 수 있습니다.
