# 다음 기회 — IT 활동 탐색

서울·경기·온라인에서 참가 가능한 해커톤, 부트캠프, 공모전을 단계별로 탐색하는 정적 웹페이지입니다.

## 기능

- 종류 선택 → 분야 선택 → 공고 목록 → 상세 정보
- 이름·기술·지역 검색, 마감일·이름순 정렬
- 온라인·오프라인·혼합 방식 필터, 조건 확인 공고 제외
- 브라우저 로컬 저장 목록
- 마감까지 남은 날짜를 한국시간으로 계산
- 모바일 화면, 키보드 탐색, 상세 대화상자

## 실행

Node.js 20 이상에서 `npm start`를 실행하고 http://127.0.0.1:4317 을 엽니다. 설치할 패키지는 없습니다.

`npm run check`로 JavaScript 문법과 공고 데이터의 기본 무결성을 검사합니다.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. 프레임워크 빌드나 서버가 필요 없습니다. `.nojekyll`로 파일을 그대로 게시합니다.

## 공고 업데이트

`catalog.json`의 `verifiedAt`과 `items`를 수정한 뒤 main 브랜치에 커밋합니다. GitHub Pages가 변경 내용을 다시 배포합니다. `id`는 기존 북마크를 보존하기 위해 유지합니다.

초기 목록은 2026년 11월 3일 대화에서 조사한 37개 공고입니다. 원문을 재조회하는 기능은 없으며, ChatGPT의 정기 조사와 이 저장소의 자동 갱신은 별도로 연결해야 합니다. 날짜 경과 표시는 브라우저에서 자동으로 갱신되지만 조기 마감·자격 변경은 자동 검증하지 않습니다.

`uncertain: true`는 휴학생 자격, 국비카드, 필수 참석 장소 등 확인할 조건이 남은 공고입니다. `deadlineTime`은 안내 문구이며 시각이 공개되지 않은 공고는 마감일 종료까지 표시됩니다. 같은 날짜에서 시각이 명시된 공고는 그 시각을 기준으로 마감을 계산합니다.

공고의 내용과 참가 조건은 주최 기관의 원문이 우선합니다. 북마크는 현재 브라우저의 localStorage에만 저장됩니다.
